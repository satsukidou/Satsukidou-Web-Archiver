石川小学校 公式ブログ PDF保存キット
=====================================

目的
----
2021年4月〜2024年3月のブログを、掲載画像を含めて月別PDFに保存し、
年度ごとに3冊へ結合します。

完成する年度別PDF
----------------
1. 令和3年度_2021-04_2022-03.pdf
2. 令和4年度_2022-04_2023-03.pdf
3. 令和5年度_2023-04_2024-03.pdf

Windowsでの使い方
-----------------
1. このZIPを展開します。
2. 「run_windows.bat」をダブルクリックします。
3. 初回のみ Playwright / Chromium の準備が入ります。
4. 36か月のページを順番に表示してPDF化します。
5. 完了すると output/yearly が自動で開きます。

大事な点
--------
- 元ページを実際のブラウザで表示して保存するため、写真もPDFに入ります。
- 途中で通信が切れたりPCを止めても、完成済みの月別PDFは次回スキップします。
- 月別PDFも output/monthly に残ります。
- サイト側の構成が変わった場合、一部の月だけ再実行できます。
- 作業中はPCをスリープさせない方が安全です。

必要なもの
----------
- Windows 11
- Python 3
- インターネット接続
